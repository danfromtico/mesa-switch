Mesa 26.2.4 Release Notes / 2026-10-01
======================================

Mesa 26.2.4 is a bug fix release which fixes bugs found since the 26.2.3 release.

Mesa 26.2.4 implements the OpenGL 4.6 API, but the version reported by
glGetString(GL_VERSION) or glGetIntegerv(GL_MAJOR_VERSION) /
glGetIntegerv(GL_MINOR_VERSION) depends on the particular driver being used.
Some drivers don't support all the features required in OpenGL 4.6. OpenGL
4.6 is **only** available if requested at context creation.
Compatibility contexts may report a lower version depending on each driver.

Mesa 26.2.4 implements the OpenCL 3.1 API, but the version reported by
the CL_DEVICE_VERSION, CL_DEVICE_NUMERIC_VERSION and CL_DEVICE_OPENCL_C_ALL_VERSIONS
clGetDeviceInfo queries depends on the particular driver being used.

Mesa 26.2.4 implements the Vulkan 1.4 API, but the version reported by
the apiVersion property of the VkPhysicalDeviceProperties struct
depends on the particular driver being used.

Bug fixes
---------

- "TY the Tasmanian Tiger 3" always crashes in the same cutscene on amd gpus
- VK_VALVE_video_encode_rgb_conversion always outputs limited color range
- X-Plane 12 (2014780) Flickering artifacts on textures with Intel Arc B580
- [DG2] ANV: Enshrouded (1203620) - character invisible, transparent billboards rendered as opaque spheres on discrete Arc GPU
- [RADV] GFX8: Black screen in UE5 DX12 (Half Sword) after commit 15990c78b8e ("allow DCC for concurrent images without DCC stores")
- anv: VK_EXT_calibrated_timestamps returns a GPU timestamp ahead of CPU time on Arc B390 (Panther Lake), crashing Unreal Engine 5.8
- asahi: Mario Kart WiiCompiled graphical glitches
- dEQP-VK.image.swapchain_mutable.wayland.2d.r8g8b8a8_srgb_r8g8b8a8_unorm_draw_texture_format_list crash
- radeonsi/va: vaGetImage to I420/YUYV fails with UNSUPPORTED_RT_FORMAT since Mesa 26.2 on GPUs with VPE (Radeon 890M)
- radeonsi: GPU page fault (SQC) / context loss when using Iris shaderpacks on RX 9070 XT (gfx1201)
- radv: NULL deref in radv_get_vgt_shader_key after binding a compute shader object
- radv: PCIe 4.0 x4 fails the "PCIe 3.0 x8" bandwidth check for VRAM command buffers by 4 MB/s (rounded per-lane constants); up to 13% decode loss in llama.cpp
- radv: UNREACHABLE clearing DEPTH|STENCIL when the dynamic render pass has no stencil attachment
- radv: VkDescriptorUpdateTemplate takes a pointer to the set_layout memory
